## Support des versions :
| Version iOS | Support |
|---|---|
| iOS ≤ 26.x | non supporté |
| iOS 27.0 dev beta 1–4 | supporté |
| iOS 27.0 public beta 1–2 | supporté |
| iOS 27.0 dev beta ≥ 5 | non supporté |
| iOS 27.0 public beta ≥ 3 | non supporté |

## Implémenté
- Pocket Poster

## Problèmes connus
- Les tweaks peuvent disparaître au redémarrage
- Le spoofing Apple Intelligence **ne fonctionne pas** sur **iPhone 15**
- Désactiver les restrictions régionales peut être cassé sur certaines versions/appareils<br>
- L'interface iPadOS et les tweaks associés peuvent ne pas fonctionner et/ou vous **bootlooper** !<br>
