## Поддерживаемые версии:
| Версия iOS | Поддержка |
|---|---|
| iOS ≤ 26.x | не поддерживается |
| iOS 27.0 dev beta 1–4 | поддерживается |
| iOS 27.0 public beta 1–2 | поддерживается |
| iOS 27.0 dev beta ≥ 5 | не поддерживается |
| iOS 27.0 public beta ≥ 3 | не поддерживается |

## Планируется:
- Файловый менеджер HouseArrest<br>

## Реализовано
- Pocket Poster
- Редактор MobileGestalt

## Известные проблемы
- Твики могут исчезать после перезагрузки
- Спуфинг Apple Intelligence **не работает на iPhone 15**
- Отключение региональных ограничений может не работать на некоторых версиях iOS/устройствах<br>
- Интерфейс iPadOS и связанные с ним твики могут не работать и/или вызвать **bootloop**!<br>

&#45; Boot Chime: Включает звук при загрузке устройства.<br>
&#45; Liquid Glass LPM: Включает Liquid Glass в режиме энергосбережения.<br>

**Аппаратные функции**<br>
&#45; Camera Control: Включает Camera Control.<br>
